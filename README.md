# Ask Me Bot

Это компактный телеграм-бот, предоставляющий возможность задавать анонимные вопросы.

После регистрации пользователь получает публичную ссылку для общения, которую он может разместить в своих социальных сетях. Это позволит другим пользователям задавать анонимные вопросы.

Для разработки использован пакетный менеджер "Poetry", который необходимо установить перед началом работы.

## Используемые технологии:
- Пакетный менеджер: "Poetry"
- ORM: "SQLAlchemy"
- Система управления базами данных: "Postgres"
- CI/CD: "Docker"
- Библиотека для работы с Telegram Bot API: "Aiogram"
- Makefile для удобного запуска и отладки

## Локальный запуск бота

1. Отредактируйте файл "example.env" и переименуйте его в ".env".

2. Установите зависимости:
    ```bash
    poetry install
    ```

3. Запустите СУБД:
    ```bash
    docker-compose -f docker-compose.local.yaml up -d
    ```

4. Активируйте виртуальное окружение:
    ```bash
    poetry shell
    ```

5. Примените миграции:
    ```bash
    alembic upgrade head
    ```

6. Запустите бота:
    ```bash
    poetry run python ./ask_me_bot/main.py
    ```
